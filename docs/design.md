# SPLAT-STREET 设计映射

斯普拉遁 2 的视觉语言：近黑侧栏、官方绿/奶油/洋红三色条纹画布、官方绿与洋红泼溅、黑色粗描边、网点纸面、硬边偏移阴影，以及昼夜两套「战场」配色。

## 三层架构

1. **ThemeRuntime Token** — `src/tokens.ts` 把色板映射到 DSH 的 `--dsw-*` 与 `--shiki-*`：背景、表面、边框、文字、状态色、按钮、链接、侧栏、阴影、代码块。明暗由 DSH 自身解析，插件只提供 `{ light, dark }` 对。
2. **自有 Skin CSS** — `src/client/skin.css` 负责画布、网点、墨点、侧栏、品牌区、Hero、Composer、对话框、代码块与外观面板。根属性与 `<style>` 由 `src/client/install.ts` 成对安装和清理。
3. **公开 Slot** — 保留 DSH 原生 Sidebar / Conversation 的行为，只注入 `sidebar.brand.mark`、`sidebar.brand.name`、`conversation.hero.brand.mark` 与 `settings.plugins.tab`。

## Dark 派生（夜间涂地）

Dark 不是 Light 的反相，而是同一套霓虹墨色换到夜间广场：

- **画布**：`#1b1b19`，由上至下 `#232321 → #1b1b19 → #201a1e`，只有底部留一点洋红余晖；叠在泼溅、极淡白色鱿鱼纹与网点上。
- **表面**：纸面 `#232321`、卡片 `#262624`、浮层 `#2c2c29`、输入框 `#282826`；分层靠表面明度差，不再用整圈白描边。
- **色相**：取色只作参考，表面统一用中性炭黑，蓝色通道最多高 1–2，避免冷灰在大面积铺开后显蓝。
- **边框**：浅墨 `#f2f2e8` 的低透明度（`0.16` / `0.30`），只做发丝线；对话框保留 `2px` 外沿 + 内侧虚线 keyline，靠黑偏移阴影与 1px 亮边立起来。
- **侧栏**：`#0d0e0d`，悬停 `#181a18`，比画布更暗，选中行仍是官方绿底黑字。
- **网点**：夜间换用白色 `screen-tone-night.svg`（9% 不透明度），与日间黑点同尺寸。
- **代码**：`#0a0a09` 配洋红关键字与电光绿字符串，保持霓虹语法。
- **文字**：`#f8f8ef` / `#e7e7de` / `#b6b6ab`，避免纯白在炭黑上过曝。
- **设置面板**：分段选择器、主题卡、Agent 预设卡、模型表单各占一档表面；选中态统一官方绿（卡片整块反白、主题卡只亮描边以保留预览图），快捷键键帽改奶油白实体键，标签页选中态用官方绿底黑字。

`--splat-canvas-veil` 控制画布纸雾透明度（内部范围 `0–0.60`，预设对应「纸白」`0.50`、「均衡」`0.12`、「涂地」`0.00`）；UI 以正向「画布墨度」百分比展示（「纸白」`20%` /「均衡」`50%` /「涂地」`100%`，滑杆 `0%–100%`），Dark 的底色透明度也读取同一 `--splat-canvas-veil` 变量，让外观面板的滑杆在两套模式下都有连续反馈。

## 组件造型

### 品牌区与 Hero

- **侧栏品牌区**：浅灰贴纸方块上的洋红鱿鱼（白色描边、内聚瞳孔）+ 白色 `SPLAT-STREET`（黑色描边）+ 白色 `DSH THEME` + 官方绿斜纹，右侧是面板折叠控件。品牌按钮本身不再是洋红胶囊。
- **新会话**：DSH 独立的 `nav > button.newSession` 变成洋红胶囊，白字、1.5px 黑边、`0 3px 0` 硬阴影，按压下沉。演示夹具用 `.splat-ui-new-session` 复刻同一外观。
- **Hero 场景**：SVG 场景嵌入基于 Inkopolis Square 游戏截图生成的透明 PNG 广场插画，叠加 `2` 招牌、`SPLAT-STREET` 胶带与墨迹装饰；夜间额外显示两侧鱿鱼。来源记录与尚未明确的素材来源见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。
- **Hero 标题**：44–74px、900 字重、轻微逆时针倾斜；日间白字 + 粗黑描边 + 黑色硬偏移，夜间白字 + 较细黑描边，保证在两套画布上都像贴纸一样立起来。模型行日间是 17px 黑字副标，夜间变成白底黑字胶带；副标右端是黑底白 `>>>` 速度块。没有白色纸板，插画直接浮在画布上。
- **响应式**：720px 与 420px 两档收窄场景与标题。

### 画布、侧栏与顶栏

- **画布**：官方绿/奶油/洋红三色条纹底 + 白色鱿鱼纹 + 洋红泼溅/倒墨 + 墨色网点 + 官方绿泼溅；右下角是白鱿鱼 + 条形码贴纸。装饰层可由外观面板关闭，只留三色底与网点。
- **侧栏**：`#242424` 底 + 左下角大鱿鱼水印 + 白色网点，右缘 3px 黑边与 `5px` 硬阴影，右下角危险条纹。选中行官方绿 + 轻微旋转 + 底部硬阴影，右端甩出一片黑描边的官方绿墨尾，黑字。
- **顶栏**：深色标题栏承载面包屑和操作按钮；下方是标签栏，日间为浅绿，夜间为深绿，选中标签使用醒目的官方绿。演示夹具额外渲染了右上角分段式昼夜开关；插件本身不注入新的顶栏控件。

### Composer、按钮与对话框

- **Composer**：22px 圆角、2.5px 黑边 + 1.5px 内圈细线、硬偏移阴影与网点；右上 `::before` 洋红滴墨，`:focus-within` 切换官方绿焦点环。附件是白纸圆盘，发送键是官方绿圆盘，底部保留阴影与内描边的间隔，`::after` 洋红涟漪。
- **按钮**：带文字按钮为黑边胶囊 + 3px 底边，悬停上浮 1px、按压下沉 2px；图标按钮保持圆形/方形几何。
- **对话框**：通用弹窗保留纸面与硬阴影；设置页采用墨黑导航、纸面表单和内缩实线。导航选中块左端端正，右端墨尾与侧栏选中行呼应，焦点环保持完整。
- **菜单与下拉**：纸面卡片 + 黑描边 + 硬阴影；悬停是淡纸色，选中项是官方绿底黑字。
- **代码块**：深色墨岛 + 霓虹语法色，顶部 banner 用代码前景色；行内代码是浅绿纸片 + 黑描边。

### 启动页与外观面板

- **启动页**：与工作区同一张三色条纹画布（泼溅、网点、鱿鱼纹）+ 白贴纸卡 + 鱿鱼徽章；进度环直接读取 `--dsh-boot-arc`，仅在 `[data-dsh-boot-spinner]` 存在时启用。
- **外观面板**：`settings.plugins.tab` 自有页面，提供「纸白 20% / 均衡 50% / 涂地 100%」三档、`0%–100%` 画布墨度滑杆、三档主墨色（默认官方绿 `#1edc00` / 荧光绿 `#9ae528` / 黄绿 `#d3f510`）、diff 语法（霓虹/中性）、装饰/网纹/字体开关、重置与关于链接。预览小卡复用全宽三色条纹画布、泼溅与网点。

## 动效与无障碍

- 所有位移、旋转与涟漪在 `prefers-reduced-motion: reduce` 下关闭。
- `prefers-contrast: more` 时强制提高画布纸面浓度，保证文字对比度。
- 输入组合控件由外壳承载焦点提示；设置导航采用内收焦点环，墨迹只装饰背景，不裁切点击区域。
